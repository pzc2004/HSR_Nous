# 追加攻击


### 9.1 触发条件

- 满足特定条件时自动触发（如"队友攻击后"、"敌人受击时"）
- 追加攻击**不消耗回合**，立即执行，不消耗 buff 回合数
- 追加攻击可以触发其他追加攻击（需检查递归上限）
- 追加攻击回能：各技能自带回能值，以数据为准（见 `05_energy_system.md` §5.1）
- 追加攻击拥有独立的**追加攻击增伤**属性
- 技能描述中含有"追加攻击"或"反击"字样的属于追加攻击；其他额外行动（终结技、再现等）**不属于**追加攻击

### 9.2 反击 (Counter)

反击是追加攻击的子类，分两型——**经典型**：目标被攻击时自动触发，对攻击者进行额外攻击；**行动触发型**：敌方**主动行动**（使用技能）即触发，无论该行动是否指向自己（云璃类；schema 发射点见 `23_event_hook_system.md` on_enemy_action）。

### 9.3 追加攻击限制

- 追加攻击**不能在控制状态下触发**（冻结/纠缠/禁锢等）
- 追加**行动**可以是**非攻击行为**（不产攻击事件，如罗刹「生息的轮转」、镜流「澹月转魄」）
- 进入战斗时触发的追加攻击，在大世界攻击的削韧/秘技伤害**之后**结算
