# 战技点机制


### 6.1 战技点上限

- 全队共享，默认上限 **5** 点
- 部分角色天赋可提高上限（如花火天赋可将上限提高至 **7** 点）

### 6.2 战技点获取与消耗

#### 常规规则

| 行为 | 战技点变化 |
|------|-----------|
| 普攻 | +1 |
| 战技 | -1 |
| 终结技 | 0 |
| 部分光锥/行迹效果 | 视具体效果 |

#### 特殊角色/机制

| 类型 | 说明 | 示例 |
|------|------|------|
| 战技不消耗战技点 | 释放战技时无视战技点消耗 | 如遐蝶、万敌战技 |
| 战技消耗多个战技点 | 单次战技消耗大于 1 点 | 如 Archer 战技消耗 2 点 |
| 普攻不恢复战技点 | 强化普攻等特殊普攻不产生战技点 | 如刃强化普攻 |
| 终结技回复战技点 | 释放终结技时额外回复战技点 | 如花火终结技 |
| 光锥/行迹额外回复 | 通过装备或被动额外获取战技点 | 如部分光锥特效 |

#### 初始战技点

进入战斗时，队伍初始拥有 **3** 个战技点。

#### 个人战技点资源

部分角色拥有**个人资源**，优先于标准战技点消耗：
- **丹恒·饮月**：「玄鳞」（Squama Sacrosancta），优先消耗，消耗视为等量战技点
- **火花**：「爆点」（Thrill），同上——通过终结技获得，可抵扣战技点消耗

### 6.5 战技点（SP）vs 秘技点（TP）—— 易混淆概念

两者**完全不同**，名字像但机制独立：

| 维度 | 战技点（SP） | 秘技点（TP） |
|------|------------|------------|
| 使用场景 | **战斗内** | **战斗外**（大世界） |
| 何时消耗 | 战技 / 部分光锥行迹效果 | 释放秘技时 |
| 上限 | 默认 5（花火被动 +2） | 默认 3（基础）→ 均衡等级 2 后 5（白厄被动 +3） |
| 初始值 | 进战时 3 | 进战前 = max |
| 战斗内回复 | 普攻 +1 / 部分技能 / 部分光锥 | **不回复**（战斗内冻结） |
| 个人资源 | 丹恒·饮月「玄鳞」、火花「爆点」 | 无 |
| 共享范围 | 全队共享 | 全队共享 |

> **不要混淆**：SP 和 TP 是两套独立的资源池。释放秘技只扣 TP 不扣 SP，战斗内战技只扣 SP 不扣 TP。

详见 [12_technique_system.md](12_technique_system.md) 关于 TP 的完整规则。
