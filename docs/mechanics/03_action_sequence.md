# 行动序

## 核心概念

战斗中有三个不同层级的时间概念，不可混用：

| 中文 | 英文 | 含义 | 粒度 |
|------|------|------|------|
| **回合** | Turn | 角色/敌人的单次行动。速度决定谁先行动，每次行动消耗一个回合。 | 最细——每个角色独立计数 |
| **轮次** | Cycle | 全局时间轴上的固定 AV 区间（如首轮 150、后续 100）。时间轴推进满预算即进入下一轮次——与任何角色的行动值消耗**无关**（AV 不跨角色求和）。独立于速度，不能被推拉条影响。 | 中——全局共享，按 AV 划分 |
| **波次** | Wave | 敌人批次。当一个波次的所有敌人被击败后，下一个波次的敌人登场。 | 最粗——按敌人组划分 |

**三者关系**：
- 一个**轮次**内，多个角色各行动若干**回合**
- 一个**波次**内，可能跨越多个**轮次**
- 转波次时（忘却之庭）会重置当前轮次 AV，所有单位重新计算行动值，但**轮次数不重置**

**示例**（忘却之庭，首轮 150 AV，后续 100 AV；希儿行动值 67、布洛妮娅 81、敌人 90）：

每个单位按**自己的**行动值在全局时间轴上独立排队，轮次只是时间轴上的刻度线：
```
波次 1 开始（3 个敌人登场，时间轴 t=0）
├── 轮次 1（t = 0 ~ 150）
│   ├── t=67  希儿行动（第 1 次）
│   ├── t=81  布洛妮娅行动（第 1 次）
│   ├── t=90  敌人行动（第 1 次）
│   └── t=134 希儿行动（第 2 次）——之后时间轴走满 150，进入轮次 2
├── 轮次 2（t = 150 ~ 250）
│   ├── t=162 布洛妮娅行动（第 2 次）
│   ├── t=180 敌人行动（第 2 次）
│   ├── t=201 希儿行动（第 3 次）
│   └── t=243 布洛妮娅行动（第 3 次）——t=250 进入轮次 3
├── 轮次 3（t = 250 ~ 350）
│   └── t=268 希儿行动（第 4 次），击败最后敌人
波次 2 开始（新敌人登场，AV 重置为新首轮 150，轮次数不重置）
└── 轮次 3 续（重置后的 150 AV 预算）
    └── ...
```

### 3.1 行动值 (Action Value)

- 总路程：10000
- 初始行动值 = 10000 / 速度
- 所有单位（我方和敌方）同时消耗行动值，谁先归零谁先行动
- 行动值归零的角色获得行动机会
- 行动后立刻回到起点，获得新的初始行动值继续参与排序
- 若多个单位行动值相同，按队伍编排顺序排序

#### 轮次机制

| 玩法 | 0 轮行动值 | 后续轮次 | 说明 |
|------|-----------|---------|------|
| 忘却之庭 / 虚构叙事 | 150 | 100 | 标准模式 |
| 末日幻影 | 300 | 100 | 长首轮模式 |
| 异相仲裁 | 300 | 100 | 长首轮模式 |

轮次特性：
- 轮次**不能被**推拉条、加速减速影响
- 轮次显示数字 = 剩余轮次数 - 1
- 轮次归 0 时战斗直接结束

角色每轮行动次数 = 轮次行动值 / 角色行动值

常见速度阈值：
- 首轮两动：10000 × 2 / 150 ≈ **133.3**
- 首轮三动：10000 × 3 / 150 = **200**

#### 战斗触发与行动推迟

| 触发方式 | 效果 |
|---------|------|
| 弱点进攻 | 造成弱点属性伤害和削韧，获取先手优势 |
| 正常进攻 | 无特殊效果 |
| 遇袭 | 我方角色行动推迟 **20** 点行动值 |
| 直接进入战斗（剧情/副本）| 无特殊效果 |

### 3.2 拉条与推条

#### 拉条（行动提前）

**立即行动**：直接将被拉条角色拉到行动条最顶端，当前行动值变为 **0**，无视当前行动值。即使因推条导致行动值超过基础行动值，也能完全拉到顶端。

**行动提前 100%**：在当前行动值基础上减去按当前速度计算的 100% 提前量，即 `当前行动值 - 10000 ÷ 当前速度`。若此前角色被推条（行动值增加），提前后可能仍需跑剩余行动值。

> **"立即行动"与"100% 拉条"的区别**：推条可使行动值超过基础值。此时"立即行动"仍能直接归零，而"100% 拉条"只能减去一个基础值的量，可能无法归零。

**行动提前 N%（0 < N < 100）**：在当前行动值基础上减去按当前速度计算的提前量：

```
行动提前后行动值 = 当前行动值 - 10000 ÷ 当前速度 × 行动提前比例
```

- 结果小于 0 时取 0

#### 推条（行动延后）

```
行动延后后行动值 = 当前行动值 + 10000 ÷ 当前速度 × 行动延后比例
```

- 结果大于 999 时显示为 999（仅显示层封顶，内部值不钳：社区实测 B站 BV1rp4y1T7wG"行动值不止999但最多显示999" + 旁证 BV1dqZyYBEya 分身 999 整局不出手；单一来源，未独立复现）

#### 后拉先动原则

当多个行动提前效果几乎同时生效，且导致多个目标行动值都为 0 时，**后变成 0 的单位先行动**。

例：B 被立即行动拉到最顶端，随后 C 被立即行动拉到最顶端，随后 E 被立即行动拉到最顶端，则行动顺序为 E → C → B。

### 3.3 速度变化

```
变化后速度 = 变化前速度 + 角色基础速度 × 加速百分比 + 固定值加速数值

变化后行动值 = 当前行动值 × 变化前速度 / 变化后速度
```

- 若当前行动值为 0，速度变化从**下一次**行动值计算开始生效
- 多回合持续的加速/减速：获得 buff 瞬间行动值按上述公式变化，后续均按变化后的速度计算初始行动值

### 3.4 额外回合与插入行动

以下行动为**插入式行动**，不消耗当前回合，不改变回合行动状态。结算顺序为**分层 FIFO**：

| 层 | 行动类型 | 说明 |
|---|---------|------|
| 1（最高） | 追加行动 | 满足条件自动触发——追加攻击，及罗刹「生之轮」、镜流「弦月飞渡」等非攻击追加行动；已触发的追加行动恒先于下层结算（可递归连锁） |
| 2 | 额外回合（**含终结技**） | 终结技（能量满时插入）、再现类额外回合（如希儿）、命途回响（模拟宇宙）——**同层按触发顺序 FIFO**，终结技不能插其他额外回合的队 |
| 3（最低） | 普通回合 | 行动轴上的正常回合（忆灵/召唤物回合有自己的 AV，属普通回合，不算插入行动） |

> 插入式行动**不消耗 buff 回合数**（因为不计入回合数）。
> 标注"不结束当前回合"的战技类额外回合（青雀/刃/波提欧战技、乱破终结技给的额外回合）排在第 2 层队列**之后**，**buff 消耗视同普通回合**（行动条位置仍不受影响）。

#### 追加攻击限制

- 追加攻击**不能在控制状态下触发**（冻结/纠缠/禁锢等）
- 追加攻击可以是**非攻击行为**（如罗刹的"生之轮"、镜流的"弦月飞渡"）
- 追加攻击可触发其他追加攻击（递归），需检查递归深度
- 进入战斗时触发的追加攻击，在大世界攻击的削韧/秘技伤害**之后**结算

#### 额外回合规则

- 额外回合优先级高于普通回合，但低于追加攻击
- 多个额外回合（含终结技）按触发顺序排队执行
- 额外回合中**不能使用终结技**
- 额外回合中 buff **不消耗回合数**，行动条位置不受影响（例外：战技类"本回合不结束"（`grant_extra_turn` 的 `after_action` 模式）仅 buff 消耗视同普通回合、正常消耗，见 §3.4 末注）

#### AV = 0 时的拉条无效

当角色的行动值已经为 0（即将行动）时，任何拉条效果都不会产生实际推进。行动完成后 AV 重置为 `10000/speed`，此时拉条才有效。

### 3.5 冻结与强烈震荡

#### 冻结

被冻结的角色，**下一次行动时无法行动**，直接结算回合。解冻后获得补偿：

```
解冻后行动值 = 初始行动值 × 50%
```

> 若未跳过行动就被解除冻结，则不会触发补偿。

#### 强烈震荡

与冻结类似，被强烈震荡的角色下一次行动时无法行动，直接结算回合。解除后获得补偿：

```
解除后行动值 = 初始行动值 × 70%
```

> 若未跳过行动就被解除，则不会触发补偿。
