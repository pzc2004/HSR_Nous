# 欢愉命途机制


### 8.1 欢愉伤害

欢愉命途（Path of Elation）角色的主要输出手段为**欢愉伤害**。与常规伤害不同，基础伤害基于**等级系数**而非角色属性：

```
欢愉伤害 = 等级系数(levelMultiplier) × 技能倍率(abilityMultiplier)
           × 原始欢愉伤害倍率(origElationDmgMulti)
           × 暴击(critMulti) × 欢愉度(elationMulti) × 笑点(punchlineMulti)
           × 增笑(merrymakeMulti)
           × 防御(defMulti) × 抗性(resMulti) × 易伤(vulnMulti)
           × 减伤(dmgMitigationMulti) × 韧性(baseUniversalMulti)
```

- 等级系数 Lv.80 = 7535.1070（约为击破等级系数的 2 倍）
- 欢愉伤害**不享受增伤**，也**不受虚弱影响**

> 英文术语对照：欢愉度 = **Elation**，笑点 = **Punchline**，好活当赏 = **Certified Banger**，增笑 = **Merrymake**，阿哈时刻 = **Aha Instant**，欢愉伤害 = **Elation DMG**。

#### 欢愉度乘区（Elation Multiplier）

```
elationMulti = 1 + 欢愉度(Elation)
```

- **欢愉度（Elation）**：欢愉命途角色的专属面板属性，可通过角色行迹、光锥、辅助效果、星魂等途径提升
- 不同角色提升欢愉度的方式不同：
  - **爻光**：通过速度转模欢愉度
  - **火花**：通过攻击力转模欢愉度

#### 笑点乘区（Punchline Multiplier）

```
punchlineMulti = 1 + 5 × X / (X + 240)
```

等价形式：`6 - 1200 / (X + 240)`，收敛到 **6**（即 +500% 上限）。

其中 `X` 的取值取决于伤害来源：
- **施放欢愉技时**：`X` = 当前笑点（Punchline）。欢愉技不仅限于阿哈时刻，也可由其他方式触发（如开拓者·欢愉终结技使目标角色立即施放一次欢愉技）
- **其他欢愉伤害**（非欢愉技的欢愉伤害）：`X` = 好活当赏（Certified Banger）

公式相同，只是数据来源不同。

- **笑点（Punchline）**：全队共享的累积值，由欢愉角色技能和部分敌人/战斗效果产出
- 笑点越多，单个笑点的边际收益越低（稀释效应）
- **前 106 个笑点**：每个使 `punchlineMulti` 绝对值增加 **>0.01**
- **前 33 个笑点**：每个使欢愉伤害**相对增幅超过 1%**（此时 `punchlineMulti` 基数低，同样的绝对增量对总伤害贡献更大）

> 欢愉伤害**不享受增伤乘区**（即不吃我方角色提供的增伤 buff），**只享受敌方易伤**。

#### 增笑乘区（Merrymake Multiplier）

```
merrymakeMulti = 1 + Merrymake
```

- **增笑（Merrymake）**：类似最终伤害的独立乘区，与好活当赏/笑点**无关**
- **稀有乘区**，目前仅以下来源可提供：
  - 爻光六星魂
  - 绯英六星魂
  - 银狼LV.999六星魂

#### 好活当赏获取方式

| 获取方式 | 说明 |
|---------|------|
| 阿哈时刻结算 | 阿哈时刻结束后，参与的欢愉角色获得好活当赏，记录消耗的笑点值，持续 2 回合（独立计时） |
| 进入战斗 | 所有欢愉角色进入战斗时获得 **20** 点好活当赏 |
| 角色技能 | 部分角色可通过技能直接为自身或队友提供好活当赏点数 |

- 多次好活当赏的笑点值**合并计算**
- 不同角色的好活当赏效果不同（爻光：队友攻击附带欢愉伤害；火花：自身技能额外欢愉伤害）

### 8.2 笑点累积

笑点（Punchline）是全队共享的累积值，获取方式：

| 获取方式 | 笑点 |
|---------|------|
| 进入战斗 | 每有 1 名欢愉角色 +1 笑点 |
| 欢愉角色普攻/战技/终结技 | 视技能描述 |
| 角色特定技能 | 视角色机制 |

---

### 8.3 欢愉编号

欢愉角色拥有特有的**欢愉编号**，标识在角色的欢愉技中：

- 编号决定欢愉技在「阿哈时刻」中的**施放先后顺序**
- **编号越小，施放越靠前**
- 通常辅助角色的编号较靠前，以便提前覆盖战斗增益
- 可理解为欢愉体系内特有的"速度"或排列优先级

---

### 8.4 阿哈时刻（Aha Instant）

当队伍中存在欢愉角色时，行动条会基于全体欢愉角色速度一定比例生成**阿哈时刻**特殊单位。

#### 阿哈速度

```
阿哈速度 = 80 + V1 × 0.2 + V2 × 0.1 + V3 × 0.05 + V4 × 0.02
```

| 符号 | 说明 |
|------|------|
| 80 | 固定基础速度 |
| V1 | 队伍中最快的欢愉角色速度 |
| V2 | 第二快的欢愉角色速度 |
| V3 | 第三快的欢愉角色速度 |
| V4 | 第四快的欢愉角色速度 |

**举例**：爻光 200 速、银狼 180 速、花火 140 速

```
阿哈速度 = 80 + 200 × 0.2 + 180 × 0.1 + 140 × 0.05 = 145
```

#### 阿哈时刻运行机制

1. **进战后触发**：进战后爻光等角色可通过技能产出初始【笑点】，阿哈发现乐子后出现在行动轴中正常跑条
2. **笑点累积**：角色进行普攻、战技、大招等行为时，战技点上方会累积一定**阿哈笑点值**（全队共享）
3. **阿哈行动**：当阿哈行动时，开启「阿哈时刻」：
   - **解除我方所有欢愉角色的控制状态**（冻结/纠缠/禁锢等）
   - 消耗当前全部阿哈笑点值
   - 按**欢愉编号从小到大**的顺序，触发全队欢愉技（每个欢愉角色各施放一次欢愉技）
   - 造成大量欢愉伤害
   - 阿哈会总结刚才的总伤害量
4. **好活当赏（Certified Banger）**：阿哈时刻结束后，参与的角色获得**【好活当赏】BUFF**（持续 2 回合，每次独立计时）
   - 该状态记录本次阿哈时刻消耗的笑点值，多次好活当赏的笑点合并计算
   - 角色头像左下方显示【好活】增益层数
   - 【好活】增益使角色可以继续造成欢愉伤害，笑点值越高伤害越高
   - 不同角色的【好活】效果不同：
     - **爻光**：使我方角色的攻击附带欢愉伤害
     - **火花**：使自身部分技能额外造成欢愉伤害
5. **多波次保留**：转波次时，阿哈时刻**不用重新跑条**（与忘却之庭中转波次时所有角色重新开始跑条不同）

> 角色行动 → 叠加阿哈笑点 → 阿哈行动触发全队欢愉技 → 阿哈笑点转变为角色笑点。
> 无论是阿哈还是角色，笑点越高造成的欢愉伤害越高。

---

### 8.5 体系特点

- **多核出伤**：欢愉体系鼓励多欢愉角色组队，提高笑点叠加效率，增加每次阿哈时刻发动的欢愉技数量
- **角色优先级 > 光锥星魂**：在规划抽取时，角色本身的优先级高于光锥和星魂
- **可拆分搭配**：部分情况下可拆分欢愉角色，搭配老角色的充能、易伤、减抗、穿透、真伤、拉条、双暴等辅助机制，组成 2~3 个队伍应对环境
- **欢愉伤害数字呈现彩色**，与其他伤害数字类型区分

### 8.6 角色示例机制

| 角色 | 欢愉度来源 | 特殊机制 |
|------|-----------|---------|
| **爻光** | 速度转模欢愉度 | 大招可直接开启 1 次额外的「阿哈时刻」；使我方角色攻击附带欢愉伤害 |
| **火花** | 攻击力转模欢愉度 | 为队伍产出额外的【笑点】；使自身部分技能额外造成欢愉伤害 |
