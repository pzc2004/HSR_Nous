# 秘技系统 (Technique System)

> **资料来源**：[Fandom wiki - Technique](https://honkai-star-rail.fandom.com/wiki/Technique)、StarRailRes `character_skills.json`

### 12.1 概念

**秘技（Technique）** 是角色的大世界技能，**只能在战斗外**释放，效果在**进入战斗时**生效。每个角色一个秘技。

跟战斗内的战技点（SP）严格区分——详见 [06_skill_points.md](06_skill_points.md) §6.3 对比表。

### 12.2 秘技点（Technique Point, TP）

#### 上限

- **基础上限 3 点**（游戏初始）
- 均衡等级 1、2 时通过「开拓者时间」任务各 +1 → 最终 **5 点**（endgame 默认上限）
- **角色秘技**可再提高：白厄秘技「终结之始」在队时上限额外 **+3 点**（即 endgame 队伍含白厄可达 8 点）

#### 初始值

进入大世界 / 战斗准备阶段时：

- `initial = max`（**初始值始终等于上限**——加 max 等于加初始可用值）
- 不存在"initial ≠ max"的机制

#### 回复方式（仅大世界）

战斗外才能回复 TP，战斗内**完全冻结**：
- 消耗品（可购买 / 合成，如「精神鼓舞」+2 TP）
- 击碎地图上的紫色可破坏物（每星球外观不同，+2 TP）

**不存在**"每回合 / 每波次回复 TP"的机制。一旦进入战斗，TP 字段不再变化，战斗内一切行为都跟 TP 无关。

### 12.3 秘技分类

按效果类型分类（参考 Fandom wiki）：

#### 攻击类（强制进战）

释放后**立即进入战斗**，对范围内敌人造成效果：
- 造成**秘技伤害**（Technique DMG，特殊伤害类型，单独结算）
- 给（对应属性）弱点的敌人施加 **20 韧性削减**
- 例子：三月七「冻人的瞬间」（冻结随机单体）、卡芙卡「宽恕无关慈悲」（雷伤 + 触电）、白厄「终结之始」（cost 2）、刃「无间地狱」、飞霄「天锋」

> 攻击类秘技释放后**短路**战前策略——其后的预置秘技不再生效。

#### 预置类（不强制进战）

施加状态进战斗，由玩家选择何时进入战斗：
- 给我方加 modifier / 召唤忆灵 / 部署 zone
- 例子：风堇「天气正好，万物可爱！」（下次进战时为我方全体回复生命 + 提升生命上限）、银狼秘技（植入弱点）

#### 领域类

在大世界创建一个**领域效果**，持续一段时间：
- 拉黑（隐身）/ 加速 等
- **同时只能存在 1 个**我方领域（新的会替换旧的）
- 进入战斗后领域效果**不延续**
- 例子：花火「迷误」（隐身）、银狼 LV.999 部署怪怪怪味豆

### 12.4 秘技点消耗

**每个秘技各自定义消耗**（来自游戏数据，不是统一规则）：

| 消耗 | 例子 |
|------|------|
| **0** | 部分纯位移 / 无消耗的预置 |
| **1**（最常见） | 三月七 / 卡芙卡 / 风堇 等大多数秘技 |
| **2** | 白厄「终结之始」 |
| **3+** | 罕见 |

> **是否强制进战**（攻击类 vs 预置类）跟 **消耗 TP 数量** 是两个独立维度。白厄秘技既消耗 2 TP 又强制进战，而三月七秘技消耗 1 TP 也强制进战。

> **未命中不耗点属大世界现象，不建模**：攻击类秘技在大世界挥空（未命中敌人）时不消耗秘技点（黄泉「四相断我」原文 "When not hitting enemies, no Technique Points are consumed."）——sim 自战斗开始起步，挥空在建模范围外（R10-R2 裁决 2026-08-15）。

### 12.5 战前策略

玩家在大世界的秘技施放顺序由玩家自由决定，没有"按速度"等强制规则：

1. 按玩家选择的顺序逐个释放秘技
2. 每释放一个扣对应 TP
3. TP 不足时可跳过 / 终止 / 强行释放（由玩家选择策略）
4. 任一**攻击类秘技**释放后强制进入战斗，**短路**后续秘技
5. 全部释放完且无强制进战时，由玩家手动攻击触发战斗

### 12.6 进战后的影响

进入战斗后：
- **所有已释放的预置秘技**生效（加 modifier / 召唤 / 部署 zone 等）
- 攻击类秘技的**秘技伤害**结算（如果命中敌人）
- TP 字段**冻结**，不再变化

### 12.7 与战技点（SP）的对比

详见 [06_skill_points.md §6.3](06_skill_points.md)。

简而言之：
- **TP**：纯战前预算，无战斗内变化
- **SP**：战斗内资源，每回合可能变化
- 二者**完全独立**，互不影响
