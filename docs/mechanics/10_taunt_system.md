# 嘲讽机制


### 10.1 基础嘲讽值

角色基础嘲讽值取决于命途：

| 命途 | 基础嘲讽值 |
|------|-----------|
| 存护 (Preservation) | 150 |
| 毁灭 (Destruction) | 125 |
| 同协 (Harmony) | 100 |
| 丰饶 (Abundance) | 100 |
| 虚无 (Nihility) | 100 |
| 记忆 (Remembrance) | 100 |
| 欢愉 (Elation) | 100 |
| 智识 (Erudition) | 75 |
| 巡猎 (Hunt) | 75 |

### 10.2 受击概率

```
角色受击概率 = 角色嘲讽值 / 队伍嘲讽值总和
```

- 行迹、技能、光锥等处可能提供嘲讽值的百分比增减
- 敌方随机攻击我方目标，取决于受击概率（根据特殊机制选择攻击目标的情况除外）
- **弹射攻击无视嘲讽**：敌人的弹射攻击不受嘲讽影响，所有角色被选中的概率相等

### 10.2.2 锁定 (Lock On)

锁定是**敌方专属机制**。当敌人锁定某角色时，该敌人的下一次行动必定攻击锁定目标，无视嘲讽值。

- **嘲讽覆盖锁定**：强制嘲讽优先级高于锁定——被嘲讽的敌人必定攻击嘲讽施加者，无视锁定

### 10.2.3 离场 (Departed) 状态

处于离场状态的角色：
- 不能被选为技能目标
- 不出现在行动序列中
- 从战场上消失，不受群体攻击影响

### 10.2.4 后备单位 (Backup)

- 敌人不能主动攻击后备单位
- 我方扩散类技能不能扩散到后备单位

### 10.3 强制嘲讽

某些技能可对敌人施加强制嘲讽状态，使其必须攻击指定目标。

**覆盖规则**：若敌人已被施加强制嘲讽，后来的强制嘲讽会**覆盖**前者——敌人改为攻击最新的施加者。

```
角色 A 施加强制嘲讽 → 敌人必须攻击 A
角色 B 施加强制嘲讽 → 敌人必须攻击 B（覆盖 A 的强制嘲讽）
```
