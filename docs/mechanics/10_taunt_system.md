# 嘲讽机制


### 10.1 基础嘲讽值

角色基础嘲讽值取决于命途：

| 命途 | 基础嘲讽值 |
|------|-----------|
| 存护 (Preservation) | 150 |
| 毁灭 (Destruction) | 125 |
| 同协 (Harmony) | 100 |
| 丰饶 (Abundance) | 100 |
| 虚无 (Nihility) | 100 |
| 智识 (Erudition) | 75 |
| 巡猎 (Hunt) | 75 |

### 10.2 受击概率

```
角色受击概率 = 角色嘲讽值 / 队伍嘲讽值总和
```

- 行迹、技能、光锥等处可能提供嘲讽值的百分比增减
- 敌方随机攻击我方目标，取决于受击概率（根据特殊机制选择攻击目标的情况除外）

### 10.3 强制嘲讽

某些技能可对敌人施加强制嘲讽状态，使其必须攻击指定目标。

**覆盖规则**：若敌人已被施加强制嘲讽，后来的强制嘲讽会**覆盖**前者——敌人改为攻击最新的施加者。

```
角色 A 施加强制嘲讽 → 敌人必须攻击 A
角色 B 施加强制嘲讽 → 敌人必须攻击 B（覆盖 A 的强制嘲讽）
```
