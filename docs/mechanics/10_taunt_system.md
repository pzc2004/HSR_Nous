# 嘲讽机制

> **资料来源**：[Fandom wiki - Taunt](https://honkai-star-rail.fandom.com/wiki/Aggro)

### 10.1 基础嘲讽值

角色基础嘲讽值取决于命途：

| 命途 | 基础嘲讽值 |
|------|-----------|
| 存护 (Preservation) | 150 |
| 毁灭 (Destruction) | 125 |
| 同谐 (Harmony) | 100 |
| 丰饶 (Abundance) | 100 |
| 虚无 (Nihility) | 100 |
| 记忆 (Remembrance) | 100 |
| 欢愉 (Elation) | 100 |
| 智识 (Erudition) | 75 |
| 巡猎 (The Hunt) | 75 |

> 注：Fandom 用 6/5/4/3 等个位数（国外惯例），国内攻略区普遍用 ×25 后的 150/125/100/75——所有值同时乘以一个常数，受击概率不变。本文档沿用国内惯例方便对照。

### 10.2 嘲讽值计算公式

跟其他属性一样：

```
嘲讽值 = 基础嘲讽值 × (1 + Σ 嘲讽百分比加成)
受击概率 = 嘲讽值 / 队伍嘲讽值总和
```

- 加成来源见 §10.4
- **特殊例外**：彦卿天赋直接修改**基础嘲讽值**（−60%），不进百分比加成项——见 §10.5
- **弹射攻击无视嘲讽**：敌人的弹射攻击不受嘲讽影响，所有角色被选中的概率相等
- 敌方随机攻击我方目标，取决于受击概率（根据特殊机制选择攻击目标的情况除外）

### 10.5 特殊：直接修改基础嘲讽值

**彦卿天赋「呼剑如影」**：**−60% 基础嘲讽值**（直接修改 Base，不进百分比加成项）

- 彦卿是巡猎命途（基础 75），天赋生效后**基础嘲讽值变为 75 × (1 − 0.6) = 30**
- 再走 `嘲讽值 = 30 × (1 + Σ 百分比加成)` 公式
- 跟其他角色的"百分比加成"区分——这种"修改 Base"的效果目前游戏里只有彦卿一例

### 10.6 锁定 (Lock On)

锁定是**敌方专属机制**。当敌人锁定某角色时，该敌人的下一次行动必定攻击锁定目标，无视嘲讽值。

- **嘲讽覆盖锁定**：强制嘲讽优先级高于锁定——被嘲讽的敌人必定攻击嘲讽施加者，无视锁定

### 10.7 离场 (Departed) 状态

处于离场状态的角色：
- 不能被选为技能目标
- 不出现在行动序列中
- 从战场上消失，不受群体攻击影响

### 10.8 后备单位 (Backup)

- 敌人不能主动攻击后备单位
- 我方扩散类技能不能扩散到后备单位

### 10.9 强制嘲讽

某些技能可对敌人施加强制嘲讽状态，使其必须攻击指定目标。

**覆盖规则**：若敌人已被施加强制嘲讽，后来的强制嘲讽会**覆盖**前者——敌人改为攻击最新的施加者。

```
角色 A 施加强制嘲讽 → 敌人必须攻击 A
角色 B 施加强制嘲讽 → 敌人必须攻击 B（覆盖 A 的强制嘲讽）
```
