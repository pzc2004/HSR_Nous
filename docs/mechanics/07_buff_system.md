# Buff / Debuff 机制


### 7.1 持续时间与结算机制

#### 回合阶段

一个常规回合分为四个阶段：

| 阶段 | 说明 |
|------|------|
| 回合开始 | 行动值降为 0，移动到行动条顶端 |
| 行动准备 | 选择技能和目标（可插入终结技）|
| 行动进行 | 播放动画，可排队插入额外行动 |
| 回合结束 | 额外行动按顺序执行，回合结束 |

#### 效果判定与结算

每个常规回合进行两次判定和两次结算：

| 时机 | 类型 | 说明 |
|------|------|------|
| 回合开始阶段 | 判定 A | 标记经过判定的 BUFF |
| 回合开始阶段 | 结算 1 | 只结算**持续伤害**和**冻结/纠缠/禁锢** |
| 行动进行阶段 | 判定 B | 标记经过判定的 BUFF |
| 回合结束阶段 | 结算 2 | 结算除持续伤害外的**所有限时状态** |

> BUFF 只有在经过一次对应类型的判定之后，再经过结算点才会减少剩余回合数。

#### BUFF 分类

| 分类 | 包含类型 | 判定时机 | 结算时机 |
|------|---------|---------|---------|
| A 类 | 持续伤害、冻结/纠缠/禁锢、遗器/光锥/战技生成的 BUFF | 判定 A 或判定 B | 结算 1 或结算 2 |
| B 类 | 部分终结技生成的 BUFF | 判定 B（行动进行）| 结算 2（回合结束）|

#### 常驻状态

部分状态不受回合结算影响（如火主的灼热意志），持续存在直到满足特定解除条件。

### 7.2 效果叠加与解除

#### 效果操作

| 操作 | 说明 |
|------|------|
| 附加 | 效果在列表中从无到有生成 |
| 刷新 | 已存在的效果持续时间重置为最新值 |
| 叠层 | 已存在的效果层数 +1，持续时间重置 |

#### 层数叠加模式

| 叠加模式 | 说明 |
|---------|------|
| 独立计时 | 每层有自己的倒计时（如 DOT） |
| 刷新持续时间 | 新层刷新所有层的持续时间 |
| 替换 | 新层覆盖旧层 |

#### 解除效果

| 类型 | 说明 | 示例 |
|------|------|------|
| 驱散 | 解除**敌方**增益效果 | 佩拉战技、罗刹终结技 |
| 净化 | 解除**我方**负面效果 | 娜塔莎/三月七/罗刹战技 |

解除规则：
- 优先解除**最后附加**的对应类型效果（LIFO，附加顺序序号最靠后）
- 标注有【不可解除】的效果不会被解除，依次往前顺延
- 净化时**不会优先解除控制类效果**，控制类与其他负面效果一视同仁

> 显示顺序：新附加的效果显示在对应效果类型栏的最上方；新刷新的效果移动至对应效果类型栏的最上方。

### 7.3 效果命中与抵抗

#### 实际命中概率

```
实际命中概率 = min(1, 基础概率 × (1 + 效果命中(EHR)) × (1 - 效果抵抗(effectRes) + 效果抵抗穿透(EFFECT_RES_PEN)) × (1 - 类型抵抗(typeRes)))
```

- `EHR`（Effect Hit Rate）：攻击方效果命中
- `effectRes`：受击方效果抵抗
- `typeRes`：受击方类型抵抗（如某些怪物对特定控制类型有额外抵抗）

#### 怪物效果属性

```
怪物效果命中 = max(0, (怪物等级 - 50) × 0.8%)
怪物效果抵抗 = 基础效果抵抗 + min(10%, 0.4% × (敌人等级 - 50))
```

怪物基础效果抵抗档位：

| 档位 | 基础抵抗 | 典型敌人 |
|------|---------|---------|
| 低 | 0% | 普通小怪 |
| 中 | 20% | 部分精英怪 |
| 高 | 30% | 多数精英怪 |
| 免疫 | 100% | BOSS / 特殊机制 |

> 我方角色的效果命中和效果抵抗初始均为 0%。

### 7.4 Debuff 分类

| 分类 | 包含效果 |
|------|---------|
| 控制类 (Crowd Control) | 冻结、纠缠、禁锢、支配、暴怒、强烈震荡 |
| 持续伤害 (DoT) | 裂伤、灼烧、触电、风化（注意：冻结和纠缠**不是** DoT） |
| 减速 (Slow) | 降低速度的 debuff |
| 虚弱 (Weaken) | 降低造成伤害的 debuff |

### 7.5 状态效果分类

状态效果分为三类：

| 分类 | 说明 | 可否驱散 |
|------|------|---------|
| 增益 (Buff) | 对己方有利的效果 | 可被敌方驱散 |
| 减益 (Debuff) | 对己方不利的效果 | 可被己方净化 |
| 其他效果 (Other Effects) | 不属于增益或减益 | **不可移除** |

### 7.6 Debuff 免疫

部分技能和消耗品可在效果命中/抵抗计算**之前**提供有限次数的 Debuff 免疫，独立于效果抵抗。

### 7.7 属性二次转化

> **资料来源**：[B 站 · 夜殇黑羽《论属性的二次转化》](https://www.bilibili.com/opus/1176311260863528979)、[米哈游官方 1.3 版本加载提示]

#### 7.7.1 概念：基本部分 + 额外部分

每个属性在内部由两部分组成：

```
属性 = 基本部分 + 额外部分
```

- **基本部分**：基础值 + 装备（光锥 / 遗器）+ 行迹 / 星魂提供的固定加成 + 角色直接获得的附加数值效果（如遗器套装固定加成、光锥固定加成等）
- **额外部分**：通过"按某属性百分比转化"得到的数值

实际战斗用的就是这个总和。

#### 7.7.2 防止二次转化规则

> **"按某属性百分比转化得到的属性值，不能再作为下一次按百分比转化的输入。"** —— 米哈游官方 1.3 版本加载提示

具体含义：如果效果是"基于属性 A 的 N% 加成属性 B"：

- 计算 B 的加成量时，**只读 A 的基本部分**，不读 A 的额外部分
- 加成产生的值进入 B 的**额外部分**

从代码层面杜绝"左脚踩右脚"的无限叠加：

```
花火 → 星期日：星期日额外暴伤 += 花火【基本暴伤】× 30%
   ↓
星期日额外暴伤涨了，但【基本暴伤】没变
   ↓
星期日 → 花火：花火额外暴伤 += 星期日【基本暴伤】× 30%（不是用涨后的总和）
   ↓
无环
```

**典型例子**：

- **万敌行迹**（生命 → 暴击）：万敌的【基本生命值】转化为【额外暴击率】
- **星期日 6 魂**（暴击 → 暴伤）：天赋的暴击率提高生效时，**目标**暴击率超过 100% 的溢出部分按每 1%→2% 转为【额外暴击伤害】（输入是目标的溢出暴击率，不是星期日自身的基本暴击率）
- **知更鸟协奏**（攻击 → 攻击）：知更鸟的【基本攻击力】转化为全队的【额外攻击力】
- **流萤行迹**（攻击 → 击破特攻）：流萤的【基本攻击力】转化为【额外击破特攻】

#### 7.7.3 4 个转化维度

每条"按属性百分比转化"的效果有 4 个独立维度（来自 B 站全角色盘点表）：

| 维度 | 默认 | 含义 |
|------|------|------|
| **是否记为转化**（输出端） | 是 | 本次转化产生的值是否归入【额外部分】——其他转化读这个属性时**排除**这部分 |
| **是否计入转化**（输入端） | 否 | 读来源属性时是否**包含其他转化产生的值**——是 = 读总和（基本 + 额外），否 = 只读基本 |
| **是否动态更新** | 是 | 是 = 跟来源属性实时联动；否 = 释放瞬间**快照锁定**（符玄战技 / 花火战技 / 大丽花 / 寒鸦等） |
| **是否连续计算** | 是 | 是 = **直接比例公式**（`来源属性 × N%`，例如花火战技"目标暴伤 += 自身暴伤 × 30%"）；否 = **离散阶梯**（"每 N 单位来源属性才给 M 单位目标属性"，例如阮·梅额外能力「落烛照水燃」"击破特攻每超过 10% 给 +6% 增伤，最多 +36%"）。**跟是否有触发阈值无关**——阈值是"超过某值才生效"的前置条件，跟公式形式正交。 |

> 注：HSR 不严格区分"属性→属性"——属性→**增伤**也纳入转化标签体系（§7.7.5 中雪衣/黑天鹅/海瑟音/阮·梅的增伤行即是实例）；opus 指出原神侧区分严格（属性→非属性曾被官方修正），HSR 侧按文本家族全部纳入。

#### 7.7.4 "百分比 + 固定值"复合 buff 的特殊处理

部分 buff 同时包含**百分比部分**（按来源属性比例）和**固定点数部分**（直接 +N 点）。本节只覆盖"百分比 + 固定点数"结构（"百分比 + 固定百分比点"的复合 buff 如星期日终结技 30%+12%（L10），见 §7.7.7，不适用本节）；目前游戏内只有两个：

- **知更鸟协奏**："提高等同于知更鸟攻击力的 #1% + #3 点"
- **玲可战技**："提高等同于玲可生命上限的 #X% + #Y 点"

固定值部分能否被再转化？**视具体 buff 而定**，两者处理方式**相反**：

| buff | 百分比部分 | 固定值部分 |
|------|----------|----------|
| **知更鸟协奏** | 不能被再转化（归入额外部分） | **也不能被再转化**（被百分比部分"牵连"，归入额外部分） |
| **玲可战技** | 不能被再转化 | **能被再转化**（独立处理，归入基本部分） |

> 这种特例需要逐 buff 单独标注，不能套用通用规则。
>
> 来源：知更鸟行的处理为 **owner 游戏内实测补充**（opus 未覆盖；玲可拆分有 opus 图6 固定行佐证）。

#### 7.7.6 四种典型组合

| 组合 | `计入转化` | `记为转化` | 含义 | 例子 |
|------|----------|----------|------|------|
| **标准转化** | 否 | 是 | 读来源只读基本、产出归入额外（其他转化读不到） | 大多数（花火 / 布洛妮娅 / 知更鸟 / 符玄 / 缇宝 等） |
| **归入基本型** | 否 | 否 | 读来源只读基本、产出也归入基本（其他转化**能**读到，但不读别人） | 昔涟额外能力 / 爻光额外能力 / 玲可星魂 / 银狼额外能力 / 黑天鹅额外能力 / 海瑟音额外能力 |
| **链式转化** | 是 | 否 | 读来源读总和、产出归入基本（**双向开放**，可吃别人 + 自己产出也能被吃） | 雪衣 / 阮·梅 / 希儿专武 / 椒丘 |
| **快照型**（与上述独立维度） | — | — | 释放瞬间锁定来源基本部分值，之后不变 | 花火战技 / 布洛妮娅终结技 / 大丽花 / 寒鸦 / 符玄 / 玲可战技 / 万敌 / 玲可星魂 |

#### 7.7.7 计算例子

**场景**：花火 ↔ 星期日 双向 CRIT DMG buff（百分比 30% + 固定 12%，星期日终结技 L10 数值）

- 花火【基本暴击伤害】 = 200%
- 星期日【基本暴击伤害】 = 150%

| 角色 | 基本部分 | 额外部分（百分比 + 固定 都在这） | 总和 |
|------|---------|----------------------------|------|
| 花火 | 200% | 百分比部分 = 30% × 星期日基本 (150%) = 45%；固定部分 = 12%（星期日给的） | **257%** |
| 星期日 | 150% | 百分比部分 = 30% × 花火基本 (200%) = 60%；固定部分 = 12%（花火给的） | **222%** |

**关键**：
- 花火给星期日的百分比读**星期日基本部分 = 150%**（不含花火给星期日加的额外部分）
- 星期日给花火的百分比读**花火基本部分 = 200%**（不含星期日给花火加的额外部分）
- 固定部分也是额外部分，同样不被其他转化读
- 无环——所有"读来源"只读基本部分
